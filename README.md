# MJA — Maria Júlia Aquatti Portfolio

Portfólio em React + Vite + CSS + Framer Motion.

## Rodar localmente

```bash
npm install
npm run dev
```

Depois abra o endereço indicado pelo Vite.

## Build de produção

```bash
npm run build
npm run preview
```

## Estrutura

- `src/App.jsx` — estrutura e conteúdo principal
- `src/styles.css` — identidade visual e responsividade
- `src/main.jsx` — entrada do React
- `public/images/` — coloque aqui as imagens reais dos projetos
